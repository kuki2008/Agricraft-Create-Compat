# AgriCraft Create Compat

Compatibility addon between Create and AgriCraft Reloaded for NeoForge 1.21.1.

## Features

- Create Harvesters can harvest AgriCraft crops.
- Uses AgriCraft harvesting mechanics.
- Supports Create contraption inventories.
- Preserves weed and crop progression mechanics.
- Keeps crop genetics relevant for automation.

## Downloads

Available on [Modrinth](https://modrinth.com/mod/agricraft-create-compat-by-kuki) and [CurseForge](https://www.curseforge.com/minecraft/mc-mods/agricraft-create-compat).

## Dependencies

- Create
- AgriCraft Reloaded
- NeoForge 1.21.1
